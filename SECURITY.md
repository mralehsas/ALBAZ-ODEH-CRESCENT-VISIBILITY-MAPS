# Security Policy

## Supported version

The actively published version is **9.6.3**.

## Reporting a vulnerability

Do not publish a security vulnerability as a public issue before the maintainer has had an opportunity to review it. Report the affected file, reproduction steps, browser version, and expected versus actual behavior through a private GitHub security advisory when that feature is enabled.

The application is a static client-side project. Avoid adding remote scripts, analytics, trackers, or untrusted dynamic HTML.
